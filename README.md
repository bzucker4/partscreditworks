# Parts Credit Works

Conversion-focused landing page for a fixed-price parts and core credit recovery audit serving independent auto repair shops.

Production domain: `https://partscreditworks.com/`

## Offer

- $295 fixed pilot
- 90 days of records
- Up to two parts vendors
- Line-by-line match and exception report
- No software migration or full accounting access

## Run locally

Open `dist/index.html` in a browser. The site is plain HTML, CSS, and JavaScript with no build step or external dependencies.
